# Security

Starlight hears your microphone, reads your screen when you ask, and can run commands you approve, so
security problems matter a lot here.

## Reporting a problem

Please report it privately, not in a public issue: use GitHub's **Report a vulnerability** button
on this repository (Security → Advisories), or write to support@starlightnotch.com.

Include what you found, how to reproduce it, and what someone could do with it. You'll hear back
within three working days, and we'll keep you updated until it's fixed. We're glad to credit you
if you'd like.

## In scope

Anything in this repository that lets an action run without its approval card, reads or sends data
a feature shouldn't, or exposes keys stored in the Keychain.

Please don't test against other people's Macs or accounts.
